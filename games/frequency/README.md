## 🎮 Game Modes

### 1. Explore Mode
- Free-form frequency creation
- Click anywhere to generate sine waves
- Pure creative expression

### 2. Harmonics Mode
- Creates harmonic series (fundamental + overtones)
- Learn about natural acoustic relationships
- Beautiful layered sounds

### 3. Ambient Mode
- Generates texture-based soundscapes
- Longer, evolving tones
- Perfect for meditation

### 4. Scales Mode
- Musical note grid based on position
- Learn musical scales interactively
- Structured harmonic exploration

## 🎛️ Controls

- **Mouse/Touch**: Create waves at position
- **Frequency Slider**: Set base frequency (80-800Hz)
- **Volume Slider**: Control overall volume
- **Preset Buttons**: Try curated compositions
- **Clear**: Remove all active waves

### Keyboard Shortcuts
- `Space`: Create wave at center
- `C`: Clear all waves
- `1-4`: Switch between game modes

## 🎨 Visual Features

- **Wave Interference**: See constructive/destructive patterns
- **Frequency Colors**: Each frequency has unique colors
- **Particle Effects**: Visual feedback for interactions

- **Grid Overlay**: Optional visual grid
